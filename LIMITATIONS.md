# Current limitations

- **Private station, not public SaaS.** Named password-authenticated accounts and inspector/reviewer/admin permissions are implemented, with explicit HTTPS-origin support for phones. No Supabase, external identity verification, invitations, production RLS or public-hosting hardening. Password change/reset and account removal UI are not yet implemented.
- **English text-focused inspection.** Clear front-facing labels and explicit field names work best. The parser supports PRODUCT/NAME, VARIANT/FLAVOR, BATCH/LOT, MFG, EXP/EXPIRY/BEST BEFORE and NET/QUANTITY. Dates use ISO YYYY-MM-DD. Curved surfaces, glare, stylized fonts, multilingual labels, handwriting and arbitrary layouts are not validated.
- **No physical defect classifier.** Printing irregularities, package geometry, tampering and seal damage are not automatically certified. A product can require a human visual review, which forces REVIEW. References also support experimental grayscale pixel comparison under reliable small-translation alignment; there is no perspective correction or trained defect classification.
- **No industrial performance claims.** Six synthetic fixtures and software tests demonstrate a functioning pipeline, not field accuracy, throughput, false-negative rates or regulatory validation.
- **Missing text is uncertain.** OCR absence cannot establish that required text is physically absent. A human must inspect the source. Recognition thresholds are heuristics, not calibrated probabilities.
- **One OCR worker per process.** Concurrent requests receive a saved uncertain result when busy. No durable job queue, cross-process lock, cancellation UI or distributed processing.
- **Small-dataset prototype.** Workspace reads currently load all inspection evidence. Large histories need pagination and summary endpoints. Uploaded images are limited, but request parsing is not a streaming upload implementation; do not expose the server publicly.
- **Original image normalization.** Stored evidence is rotated, metadata-stripped PNG, possibly resized to 2400px. Raw upload bytes and EXIF are not retained. Bounding boxes refer to the normalized image.
- **Retention.** Replaced reference images remain for historical snapshots. Guest sessions and unused assets are not automatically purged. Inspection deletion removes inspection evidence/reviews while retaining metadata-only audit events. Complete local erasure requires stopping the server and removing the data directory and backups yourself.
- **Audit is application-level.** Reviews append through the API, but a person with filesystem access can alter SQLite. No tamper-proof signature or external audit storage.
- **Optional Gemini not live-tested.** Mocked transport covers failures and schema validation. No key was configured. Billing status cannot be verified; never supply a billing-enabled key. Optional observations do not automatically identify required defects.
- **Reports use browser printing.** Save as PDF depends on the browser. JSON evidence export is supported; there is no signed certificate or server PDF renderer.
- **No deployment performed.** This repository is a functional local prototype. Production security and deployment gates are listed in DEPLOYMENT.md.
- **Phone hardware remains unverified.** Windows Edge tests exercise mobile layout and a virtual camera, including track shutdown after capture. Physical Android/iOS cameras, LAN TLS and certificate installation have not been tested. Ubuntu instructions are provided but have not been executed here.
